# ZaySine by Flash Tech

ZaySine (ဈေးဆိုင်, “shop”) is the platform name in both interface languages. Keep the supplied Flash Tech artwork as the secondary attribution.

The generated ZaySine mark depicts a neighborhood storefront with a terracotta awning, an amber sun and a subtle Z in the counter. The master image is `design/zaysine-logo-source.png`. The header uses `public/zaysine-logo.webp`; PNG exports are available at 192 and 512 pixels, plus a 180-pixel Apple touch icon. The 512-pixel image also serves as the maskable installation icon.

The theme uses deep teal (`#174e50`), terracotta (`#a83e28` for accessible white-text buttons), amber (`#f2ba55`) and warm cream (`#fff8ed`). Flash Tech's original gold and slate logo remains unchanged.

The installed app ID remains `/`. Database names, Compose project identity, volumes and Redis namespaces are operational settings and are not renamed as part of the brand change. The service worker removes only the old Neighbour/ZaySine static-shell caches when the new shell activates.
